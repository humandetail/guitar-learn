# 吉他体验馆：试听、试弹与三关练习

Status: ready-for-agent

日期：2026-11-16（Asia/Shanghai）

## Problem Statement

初学者在学习弦号、品位、空弦和和弦时，需要在认琴图、指板题、参考音和六线谱之间来回切换。没有真琴在手时，学习者很难当场验证「这根弦是什么音」「再按高一品会怎样」或「扫过去哪些弦会响」。遇到真琴上的杂音和换和弦卡拍时，还需要找到对应的教学和工具。

## Solution

在 Web 版「学习」首页新增「吉他体验馆」，并从「拿稳琴，认清弦与品位」的空弦和品位步骤接入对应试弹。体验馆提供「听一听」「认识它」「弹一弹」「闯关学」「真琴提示」。初学者可以听三种弹法、认识 11 个琴体部位、在 2D 或 3D 木吉他上自由弹，再经历从拨单音到跟拍换和弦及弹完整首《小星星》的过程。完成后能打开课程、曲库或练习工具，在真琴上继续。

| 阶段 | 交付内容 |
| --- | --- |
| 一 | 2D 指板、自由弹、音高和琴弦反馈、首页和课内入口 |
| 二 | 三种试听、认琴热点和随概念试弹 |
| 三 | 三关练习、本地进度、真琴提示与相关入口 |
| 四 | 可旋转、缩放、试弹的 3D 木吉他展台，共用前述交互和进度 |

## User Stories

1. 作为初次到访者，我希望从「学习」首页直接进入体验馆，以便打开网页就能试琴。
2. 作为正在学空弦的用户，我希望从课程的当前步骤打开空弦试弹，以便边看解释边听音。
3. 作为正在学品位的用户，我希望从课程直接试同弦的相邻品位，以便理解按弦会改变音高。
4. 作为从课内进入体验馆的用户，我希望返回原课、原步骤和既有自查状态，以便继续刚才的学习。
5. 作为初学者，我希望进入页面后由我主动播放，以便自己决定何时出声。
6. 作为试听者，我希望分别听扫弦、分解和弦和短旋律，以便分辨三种弹法。
7. 作为试听者，我希望看见当前播放状态并能随时停止，以便反复对比。
8. 作为认琴的新手，我希望点选 11 个部位并看见对应位置，以便在真琴上找到它们。
9. 作为认琴的新手，我希望能从部位列表切换热点，以便在手机上也能选中较小的部位。
10. 作为刚开始试弹的用户，我希望依次拨响六根空弦，以便比较从第 6 弦到第 1 弦的音高。
11. 作为刚开始学按弦的用户，我希望比较同一根弦的 0、1、2 品，以便听出相邻品位的区别。
12. 作为自由弹的用户，我希望每根弦都能独立选品位和松开，以便在 0–12 品试音。
13. 作为自由弹的用户，我希望按下品格后还可以选择何时拨弦，以便理解按弦和拨弦是两个动作。
14. 作为自由弹的用户，我希望拨弦时看到弦高亮、弦号、品位和音名，以便知道刚才弹了什么。
15. 作为自由弹的用户，我希望快速连续拨弦时各音可以自然延续，以便听清一串音或一组和弦。
16. 作为触屏用户，我希望沿琴身划过琴弦就能按顺序扫响，以便练习上下扫弦。
17. 作为触屏用户，我希望只在扫弦区域触发扫弦，手势结束后能继续滚动页面，以便浏览教学和谱面。
18. 作为使用鼠标或按钮的用户，我希望可以拖扫或点击上下扫弦按钮，以便选择合适的操作方式。
19. 作为使用键盘的用户，我希望能用键盘拨弦、扫弦和换和弦，以便连续练习而无需操作鼠标。
20. 作为和弦初学者，我希望一键切换几个常用和弦并看到指法图，以便把看到的指法和听到的声音对应起来。
21. 作为和弦初学者，我希望扫弦时跳过指法图中标记为 X 的弦，以便了解哪些弦应发声。
22. 作为需要空弦的用户，我希望一键解除按弦和和弦选择，以便回到标准调弦的六根空弦。
23. 作为左手持琴用户，我希望琴体与对应指法图按我的持琴方向显示，以便对照真琴辨认位置。
24. 作为左手持琴用户，我希望弦号、品位、音高和六线谱的读取规则保持一致，以便顺畅地从琴面读回六线谱。
25. 作为第一关的学习者，我希望按提示找弦并比较同弦的不同品位，以便把音高变化与位置联系起来。
26. 作为第二关的学习者，我希望先听预备拍，再跟着 4/4 拍的提示扫弦和切换和弦，以便找到换和弦时机。
27. 作为跟拍困难的学习者，我希望随时降速并重来，以便先练稳动作。
28. 作为第三关的学习者，我希望在六线谱上看见当前目标弦、品位和节奏提示，以便跟着弹《小星星》。
29. 作为第三关的学习者，我希望先反复练两小节，再弹完整旋律，以便把短句连起来。
30. 作为弹错的学习者，我希望看到具体弹错的弦、品位、和弦或节拍，以便修正动作后继续。
31. 作为已经通关的用户，我希望随时重练每一关，以便复习容易卡住的部分。
32. 作为回来复习的用户，我希望刷新或重新打开后还能看到本浏览器保存的通关进度，以便继续练习。
33. 作为课程用户，我希望仍能照常继续原有课程和自查，以便自行安排体验馆与真琴练习的顺序。
34. 作为准备拿真琴的用户，我希望知道按弦杂音、换和弦卡拍、调音和持琴在真琴上是什么样，以便知道下一步练什么。
35. 作为遇到真琴问题的用户，我希望从提示直接打开对应课程、调音或节拍器，以便当场尝试解决。
36. 作为想观察琴体的用户，我希望旋转和缩放 3D 木吉他并点选部位，以便从不同角度理解琴体结构。
37. 作为使用 3D 展台的用户，我希望能在模型上点品格、拨单弦和划弦，以便在同一把琴上边看边试。
38. 作为切换视图的用户，我希望保留已按品位、和弦及当前闯关位置，以便在 2D 与 3D 之间接着弹。
39. 作为设备暂时无法显示 3D 的用户，我希望仍可用 2D 完成相同的试听、试弹和闯关任务，以便继续学习。
40. 作为手机短屏用户，我希望弦、扫弦按钮、当前目标与反馈容易触达，以便不放大页面也能练习。
41. 作为离开页面或切到后台的用户，我希望试听、拨弦余音和节拍一起停止，以便回来后由我决定何时继续。
42. 作为切换到调音或逐弦和弦检测的用户，我希望体验馆停声，以便扬声器里的合成音不会干扰麦克风读数。
43. 作为遇到音频启动失败的用户，我希望看到明确状态并能主动重试，以便恢复发声。
44. 作为看到通关结果的用户，我希望区分屏幕上的弹奏练习与真琴上的演奏自查，以便知道哪些动作还需要在真琴上练。

## Implementation Decisions

- Web 体验馆使用项目现有视觉风格、自制或可再分发的木吉他模型、项目内的曲谱和自有教学文案。默认先呈现可立即使用的 2D 界面，3D 模块与模型按需加载。加载中、加载失败或设备不支持 3D 时，继续提供 2D 操作。
- 首页提供独立入口。空弦和品位步骤打开对应概念练习，返回沿用现有课程导航，恢复进入前的课程位置及自查。真琴提示连接现有课程、调音器、节拍器或曲库。
- 试听采用项目的合成音色和既有曲谱数据，内容覆盖扫弦、分解和弦和短旋律。认琴复用现有 11 个部位的名称、位置和用途。概念试弹覆盖弦、品、空弦、扫弦、和弦与和弦图。
- 2D 和 3D 共用每弦品位、所选和弦、最近发声的音、基准音及练习状态。沿用标准调弦 E2、A2、D3、G3、B3、E4 与可设置的 A4 基准音。按品位与发声分别处理。选择和弦时把现有指法载入琴面，手动改品时如实反映当前指法。六线谱仍遵循上 1 弦、下 6 弦。
- 自由弹提供空弦状态及 C、G、Am、Em 等现有指法。按住某一品后拨弦，以该弦的当前品位发声。扫弦沿实际跨过的弦顺序触发，跨过多根弦也保留顺序。同一扫弦方向内每根弦触发一次，方向反转后可以再次触发。和弦指法中的 X 弦静音。键盘提供 1–6 拨弦、空格扫弦及可见的和弦快捷键，快捷键只作用于当前弹奏区域，保留常规控件的键盘操作。
- 实时拨弦复用音高计算、音频生命周期和参考音合成方式，支持多根琴弦相邻起音和余音叠加。试听和实时弹奏争用时由最新的主动操作接管。离开体验馆、切到后台或麦克风接管时，取消已排程的体验馆声音、余音和节拍，以及尚在等待解锁的播放请求。返回后由用户重新触发。体验馆的试弹依赖浏览器生成的声音及输入动作。
- 第一关以六根空弦和同弦 0、1、2 品为内容，依据用户输入的弦与品位反馈。第二关复用 4/4 节拍时钟，预备拍后提示扫弦位置和 G、C 切换，支持降速与重试。跟拍判定使用与播放一致的时钟，按拍速提供容错，以早拍、晚拍、选错和弦等可读反馈引导重练。
- 第三关复用曲库《小星星》的旋律、六线谱呈现与示范调度。先做两小节练习，可反复重来，再完成整首旋律。谱面中的重复音分别拨，长音提示保持时值。错弦、错品时标出当前位置并允许重试。体验馆的通关结果依据屏幕上的动作与对应规则。
- 三关以稳定标识保存通过状态，刷新后继续显示。体验馆进度使用本地存储，独立于课程进度、自查和逐弦和弦检测的练习记录。保存失败时保留当前会话结果并显示重试入口，读到损坏进度时给出说明，保留原数据供恢复。
- 保留标准按钮、部位列表和文字反馈作为 3D 热点及手势的等效操作。左手模式镜像琴面与相应指法图。手机优先露出当前操作的品位、拨弦和扫弦控件，高把位通过指板自身导航可达，页面在短屏上保持可滚动。

## Testing Decisions

- 主验收采用现有 Playwright 的 Web 页面入口。从用户可操作的按钮、键盘和手势输入出发，检查可见状态、反馈、进度和浏览器发声。以覆盖完整流程为主，避免绑定组件结构、内部状态形状或 3D 渲染实现。
- 路径一从「学习」首页进入体验馆，分别试听、点选认琴部位、拨单弦、上下扫弦、换和弦并完成三关。覆盖点错后修正、跟拍降速、两小节到全曲、刷新恢复通关状态、切换 2D/3D 保持品位和关卡，以及 3D 不可用时的 2D 通关。
- 路径二从「拿稳琴，认清弦与品位」的空弦步骤进入，试拨标准空弦并比较相邻品位，随后返回原课。覆盖课内位置与既有自查、左手模式的琴面镜像与六线谱弦序、键盘与手机短屏主操作。
- 音频沿用扩展课程与曲库测试的浏览器观测方式，保留真实 Web Audio 调度，在边界观察基准音和品位对应的频率、向上向下扫弦的发声顺序、X 弦静音与停声。覆盖切到后台、离开体验馆和麦克风接管，包括尚在等待音频解锁时切走。节奏流程参考节拍器现有测试，进度恢复参考课程和基础乐理现有测试。
- 桌面 Chrome 和 iPhone Safari 分别手动核验试听和拨弦实际出声、扫弦跟手与后续页面滚动、3D 旋转／缩放与点按、左手模式，以及切后台和进入麦克风检测时停声。短屏布局沿用项目已有的窄屏与横屏验收尺寸。浏览器自动化结果与真机结果分别记录。

## Out of Scope

- 微信小程序和 iOS 移植、吉他之外的新乐器。
- 账号、后端、云同步、社区排行和分享成绩。
- 麦克风识别屏幕闯关成绩、扫弦识别、手型识别、按弦力度判定。真琴自查与现有逐弦和弦检测各自沿用原有语义。
- 新的曲谱编辑器、外部曲库接入、替代调弦与变调夹。

## Further Notes

- 借鉴 [找Tab 的吉他体验](https://www.zhaotab.com/instruments#guitar) 中边看琴边试弹的交互。体验馆使用《小星星》及项目已有的曲谱内容衔接现有学习路线。
- 规格按「先让 2D 可完整演奏，再加入同一套交互的 3D 展台」排序。发布到本地 issue tracker 后，编码仍由单独的开始实现指令启动。
