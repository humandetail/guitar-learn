# 03 — 内置和弦查看、参考音与指法显示偏好

**What to build:** 用户浏览十个基础开放和弦的固定指法，试听整和弦或单弦，并按自己的持琴方向和学习需要保存图示偏好。

**Blocked by:** 02 — 六弦调音与基准音设置。

**Status:** ready-for-agent

## Acceptance criteria

- [ ] 提供 C、D、E、G、A、Am、Dm、Em、A7、D7 各一种固定开放指法，图示与参考音共用数据；内置资料不可直接编辑或删除。
- [ ] Am 按第 6→1 弦为 x02210，第 4 弦第二品指 2、第 3 弦第二品指 3、第 2 弦第一品指 1；C 为 x32010，图示弦号和音高正确。
- [ ] 整和弦从第 6→1 弦快速依次合成发声、跳过不弹弦；点击可弹奏弦只播放该弦。标注“合成参考音”，采用一种清晰、音高准确的拨弦音色，跟随共用基准。
- [ ] 手指编号默认显示，可关闭；默认右手持琴，可镜像，镜像保留弦号，不改变资料顺序、音高。偏好保存并在重开后恢复。
- [ ] 提供和弦库与设置的可达入口，按方向 A 的六弦指法图、状态与主操作呈现；不把生成图中的错误指法或重复状态照搬到页面。
- [ ] 麦克风检测启动后停止参考音，检测期间不可重播；结束后须用户再点击，不自动播放。
- [ ] 从浏览器验证图示、整和弦／逐弦播放、基准变化及显示偏好，交付相关测试与音高证据，遵循[共用约定](README.md)。

## 人工验收 — 8–10 分钟

1. 约 3 分钟：浏览内置列表，校对 Am、C 和另一个和弦指法。
2. 约 3 分钟：整和弦／单弦试听，修改基准后抽查目标音高。
3. 约 2–4 分钟：切换镜像、关闭编号、刷新，确认资料与偏好；抽查启用调音后参考音停止。
