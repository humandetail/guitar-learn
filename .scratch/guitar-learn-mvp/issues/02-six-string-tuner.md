# 02 — 六弦调音与基准音设置

**What to build:** 用户通过六弦轨道选择标准空弦、读取实际音高和调弦提示，并在设置中调整及保存全应用共用的基准音。

**Blocked by:** 01 — E2 调音首条可用链路与音频能力验证。

**Status:** ready-for-agent

## Acceptance criteria

- [ ] 默认目标第 6 弦 E2；六根目标音按第 6→1 弦为 E2、A2、D3、G3、B3、E4，显示目标弦、目标音、有效实际音名／八度和带符号音分。
- [ ] ±5 音分含边界显示“已调准”；超出此区间且位于 ±100 内时，偏低提示调高、偏高提示调低；绝对值大于 100 显示大偏差核对提示，不再显示方向指令，始终保留有效读数。
- [ ] 基准 A4 默认 440 Hz，范围 430–450 Hz、步长 1 Hz，提供恢复 440 Hz。使用十二平均律；设置本地保存，重开恢复但不启动音频，供后续参考音和检测共用。
- [ ] 目标或状态改变不把旧实测值当作新目标的有效结果；等待无稳定输入时不残留当前有效判断。音分指针与实际数值一致，超出可视刻度不伪造位置。
- [ ] 按已选六弦工作台呈现选弦、读数、状态和拇指可达操作；完成相关 UI 和设置错误提示，继承停止、权限和后台规则。
- [ ] 交付 ±5、±100 及界外行为测试、基准持久化测试与六弦真实收音／响应证据，遵循[共用约定](README.md)。

## 人工验收 — 8–10 分钟

1. 约 3 分钟：选择六根弦并抽查实际收音，确认弦号、音名及八度。
2. 约 2 分钟：改为 441 Hz、刷新确认恢复，再一键恢复 440 Hz。
3. 约 3–5 分钟：复核边界用例与六弦设备报告，抽查偏高／偏低及大偏差反馈。
