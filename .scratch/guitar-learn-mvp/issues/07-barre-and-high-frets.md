# 07 — 高把位与横按和弦的编辑和使用

**What to build:** 用户编辑带手指提示、横按或高把位的自定义指法，保存后准确查看实际品位并试听目标音。

**Blocked by:** 06 — 自定义和弦新增、复制、编辑与删除。

**Status:** needs-info

**Implementation:** implemented — 软件流程已落地，所涉及的人工／实机验收待补齐。

## Acceptance criteria

- [ ] 完整支持不弹、空弦及第 1–24 品，指法图高把位可辨认实际品位，不把高把位误画成第一品。
- [ ] 自定义手指编号可不填，填写时仅为 1–4；支持选填横按品位、起止弦和手指编号，图示横条正确。
- [ ] 编辑、保存与重新打开均保留手指／横按资料，未填编号只显示按弦位置。关闭编号仅影响图示提示，不隐藏必要编辑能力。
- [ ] 与弦品位明显冲突的手指或横按资料禁止保存并定位错误；横按上方的独立按弦允许存在，不评估指法人体工学。
- [ ] 图示、镜像及参考音使用同一份指法；参考音遵循共用基准，高把位目标音和八度正确，不因横按资料改变逐弦音高定义。
- [ ] 交付合法／冲突资料、24 品边界、镜像与保存往返的测试，以及相关参考音核对证据；适用条件见[共用约定](README.md)。

## 人工验收 — 8–10 分钟

1. 约 3 分钟：创建横按与高把位样例，查看实际品位、试听并重开。
2. 约 2 分钟：关闭编号和镜像，检查音高、弦号及资料不变。
3. 约 3–5 分钟：输入明显冲突资料与合法的横按上方按弦，复核错误定位和边界测试。
