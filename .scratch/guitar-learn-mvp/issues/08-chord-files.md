# 08 — 自定义和弦文件备份与批量导入

**What to build:** 用户通过独立和弦 JSON 文件备份全部自定义资料，或批量导入后立即查看和试听；无效文件和写入失败不会破坏现有库。

**Blocked by:** 07 — 高把位与横按和弦的编辑和使用。

**Status:** needs-info

**Implementation:** implemented — 软件流程已落地，所涉及的人工／实机验收待补齐。

## Acceptance criteria

- [ ] 固定本应用和弦 JSON 格式及可用示例，支持多条名称、六弦状态、可选手指和横按资料，不接受图片、谱站链接或其他软件格式。
- [ ] 一键导出全部自定义和弦，不把内置十个和弦重复导出；文件可经同一入口重新导入，指法及附加资料无损保留。
- [ ] 导入前整份校验，包括名称、六弦数量、范围、全不弹和手指／横按一致性；任一无效整份拒绝，明确具体条目与原因，现有资料不变。
- [ ] 同名自动追加不冲突后缀，包括文件内同名和重复导入；不覆盖已有资料，导入身份不能覆盖现有稳定 ID。
- [ ] 写入失败时零部分导入，保留原库及待导入内容，明确未保存并可重试；成功条目可立即展示和试听。
- [ ] 数据管理中和弦导入／导出有清晰入口，说明文件用于备份迁移、本地保存限制；记录文件不得误用为和弦资料。
- [ ] 交付文件往返、同名、格式错误、数据错误及写入故障的浏览器验证，遵循[共用约定](README.md)。

## 人工验收 — 8–10 分钟

1. 约 3 分钟：导出并重新导入含横按资料的自定义库，核对图示和名称后缀。
2. 约 3 分钟：导入含一条无效资料的多条文件，确认无新增并定位问题。
3. 约 2–4 分钟：模拟写入失败，检查原库不变、内容保留及重试，复核测试报告。
