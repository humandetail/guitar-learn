# 12 — 练习记录独立备份与恢复

**What to build:** 用户使用独立记录 JSON 文件备份全部练习历史并恢复合并，重复恢复不新增重复记录，冲突不会覆盖现有结果。

**Blocked by:** 09 — 完成一轮 Am 检测并保存结果。

**Status:** needs-info

**Implementation:** implemented — 软件流程已落地，所涉及的人工／实机验收待补齐。

## Acceptance criteria

- [ ] 固定独立记录文件契约，含格式版本、稳定记录 ID、练习时间、目标名称及指法快照、当轮基准、逐弦结果；导出全部记录，不混入和弦备份。
- [ ] 在数据管理提供导出和恢复入口；恢复前整份校验，结构无效、版本不支持或误用和弦文件则整份拒绝并提示原因。
- [ ] 有效恢复与现有记录合并，同 ID 同内容去重、保留已有记录；同 ID 不同内容整份拒绝并提示冲突。文件内部重复 ID 采用相同规则，不做静默覆盖。
- [ ] 重复恢复同一备份数量不增加；新记录及历史详情可经已有结果／详情能力核对，恢复不向和弦库新增资料。
- [ ] 校验或写入失败保持现有记录不变，不留下部分恢复，不显示成功；保留待恢复文件并提供重新尝试路径。
- [ ] 交付导出／恢复往返、重复 ID、冲突、无效／未知版本及写入失败的浏览器测试，遵循[共用约定](README.md)。

## 人工验收 — 8–10 分钟

1. 约 3 分钟：导出记录，恢复到有部分相同记录的状态并重复恢复，核对数量和详情。
2. 约 3 分钟：恢复既有 ID 冲突和文件内冲突样例，确认原记录完整保留。
3. 约 2–4 分钟：抽查未知版本、格式错误及写入失败证据，确认不新增和弦。
