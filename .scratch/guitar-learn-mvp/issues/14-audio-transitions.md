# 14 — 跨模块练习时的音频切换与中断恢复

**What to build:** 用户组合使用节拍、参考音、调音和逐弦检测时，能明确控制收音与播放的切换，并在中断后手动恢复到可预期的练习状态。

**Blocked by:** 05 — 拍号、细分与下一小节切换；10 — 从任意内置或自定义和弦发起检测。

**Status:** ready-for-agent

## Acceptance criteria

- [ ] 启动调音或逐弦检测后暂停应用 click、停止正在发出的参考音，并阻止检测期间其他入口重新播放；视觉节拍可继续，按已选交互清楚表达声音暂停状态。
- [ ] 检测结束不自动恢复 click，提供“恢复节拍器声音”动作；不绕过用户关闭声音或后台暂停状态。参考音需用户再次点击播放。
- [ ] 调音与逐弦检测互斥，切换时停止并释放原麦克风使用；从未完成检测切调音器明确提示本轮不会保存，无部分记录。
- [ ] 权限拒绝、设备不可用、断开时展示原因和重试入口，未完成本轮放弃，其他模块仍可使用，声音按手动恢复规则处理。
- [ ] 后台暂停节拍、停止麦克风并释放资源，未完成本轮放弃；返回提示本轮未保存，调音／检测须重新开始，节拍用户手动继续从第一拍开始，不补播或自动重启。
- [ ] 等待、有效错音、权限失败和未保存反馈保持不同语义，恢复按钮和禁用状态与实际音频行为一致；不声称验证手型或来源弦。
- [ ] 在各功能既有安全停止和释放能力基础上，交付跨模块组合场景浏览器测试与移动／桌面真实切换、中断恢复证据，遵循[共用约定](README.md)。

## 人工验收 — 8–10 分钟

1. 约 3 分钟：启动含细分节拍再开检测，检查 click 暂停、视觉继续；退出后确认不自动响，手动恢复。
2. 约 2 分钟：播放参考音后开检测，尝试重播，停止检测后重新点击播放；从检测切调音检查互斥和放弃反馈。
3. 约 3–5 分钟：检查后台返回、断麦／重试及用户本已关闭声音的恢复行为，复核设备证据。

## 规格对应
