# 05 — 拍号、细分与下一小节切换

**What to build:** 用户选择每小节拍数和细分密度，运行中可预期地在下一小节统一切换练习节奏。

**Blocked by:** 04 — 可调速的基础节拍练习。

**Status:** ready-for-agent

## Acceptance criteria

- [ ] 每小节可选 2、3、4 拍，默认 4；四分、八分、十六分每拍分别产生 1、2、4 次 click，BPM 始终表示每分钟主拍数。
- [ ] 视觉跟随每次细分，区分主拍、细分、小节第一拍并显示拍位置；关闭声音仍维持完整视觉节奏。拍轨数量随实际拍数变化，不为设计语法固定成四拍或六拍。
- [ ] 停止时改参数立即生效；运行中 BPM、拍数、细分在下一小节第一拍统一应用，期间明确显示“下一小节应用”，不混用新旧规则。
- [ ] 新增设置本地保存、重开恢复但不自动启动。参考已选设计的首次四分状态，不增加 Tap、循环或其他节奏功能。
- [ ] 交付参数组合、切换时机、静音视觉与恢复测试；前台在 30、80、240 BPM 各运行 60 秒，十六分细分均覆盖，累计时间偏差不超过 100 毫秒、无漏拍或连发，视觉与声音对应。
- [ ] 证据测量实际发声时刻而非仅预排时间或回调，设备范围与 UI 按[共用约定](README.md)。

## 人工验收 — 8–10 分钟

1. 约 3 分钟：依次选择 2／3／4 拍和三档细分，检查重音与视觉。
2. 约 2 分钟：运行中同时修改三类参数，检查下一小节统一切换，静音后视觉不变。
3. 约 3–5 分钟：复核三组 60 秒时序证据与设置重开结果。
