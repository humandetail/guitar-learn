# 06 — 自定义和弦新增、复制、编辑与删除

**What to build:** 用户创建或复制和弦、编辑名称与六弦指法、本地保存后立即查看和试听，并经确认删除自己的资料。

**Blocked by:** 03 — 内置和弦查看、参考音与指法显示偏好。

**Status:** needs-info

**Implementation:** implemented — 软件流程已落地，所涉及的人工／实机验收待补齐。

## Acceptance criteria

- [ ] 提供新增、复制内置和弦、编辑自定义和弦的入口与六行编辑表，弦序固定为第 6→1 弦；内置和弦仍不可直接修改或删除。
- [ ] 名称非空、恰有六根弦，每弦为不弹／空弦／1–24 品、至少一根可弹奏；错误指出条目或弦位置，不写入无效内容。横按与高把位专项交互在 07 完成。
- [ ] 为自定义资料赋稳定 ID，集中本地读写；编辑保留身份，新建／复制创建独立身份，重开资料仍在。
- [ ] 新增、复制或编辑与其他资料同名时保留已有资料，为待保存名称自动添加唯一后缀；正常编辑自身不应误当作与自己同名。
- [ ] 保存后可在自定义库查看同一份指法并试听；删除须确认，取消不变，内置库不受影响。
- [ ] 写入失败时保留原资料和未保存表单，明确未保存并提供重试；显示仅当前浏览器保存的提示，不静默丢弃或虚假成功。
- [ ] 交付新增到试听、刷新、编辑、同名、删除取消／确认及失败重试的用户流程测试；UI 与其他适用条件按[共用约定](README.md)。

## 人工验收 — 8–10 分钟

1. 约 3 分钟：复制 Am、同名保存、查看和试听；新增一个简单指法。
2. 约 2 分钟：修改并刷新，取消删除后再确认删除，检查内置资料保留。
3. 约 3–5 分钟：检查无效弦值及可复现的写入失败，确认内容保留、可重试。
