# 13 — 保存失败后的结果救回

**What to build:** 用户完成检测却遇到本地空间不足或写入异常时，仍能查看结果、导出本次结果，或清理旧记录后回来重试，不丢失这轮练习。

**Blocked by:** 11 — 练习记录回顾与清理；12 — 练习记录独立备份与恢复。

**Status:** ready-for-agent

## Acceptance criteria

- [ ] 在既有保存失败保留结果基础上，清楚显示“本轮未保存”和原因，检测完成不等于记录已保存，不展示虚假成功。
- [ ] 提供重试保存、导出本次结果和查看并清理旧记录的可达动作；清理后返回仍保留这轮结果，不因页面内导航丢失待保存内容。
- [ ] 本次结果导出使用 12 的记录备份格式及本轮稳定 ID、快照、基准、逐弦结果，可经已有恢复入口读回。
- [ ] 重复点击重试或先恢复再重试不创建重复记录，同 ID 不同内容不静默覆盖；保存成功后状态准确更新。
- [ ] 清理只影响用户确认删除的旧记录，不改变自定义和弦或设置，取消清理仍可返回未保存结果。
- [ ] 提供可重复的写入失败测试场景，从用户动作验证保留、导出恢复、清理返回、重试和防重复全流程，遵循[共用约定](README.md)。不承诺刷新或关页后未保存内容自动恢复。

## 人工验收 — 8–10 分钟

1. 约 3 分钟：在可复现的空间不足场景完成一轮，核对未保存提示及全部结果仍可查看。
2. 约 3 分钟：导出本次结果并恢复，核对内容与身份一致。
3. 约 2–4 分钟：复现失败，清理旧记录、返回并重试，重复触发确认无重复，核对和弦与设置未变。

## 规格对应

P07、B14、Q55；方向 A 的本轮保存失败状态。只扩展记录救回流程，和弦写入失败已由 06／08 处理。
