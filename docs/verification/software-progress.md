## 执行顺序更新

用户先选择保留指定库并自行实测，随后说明“我现在手上没有琴，要怎么办，你能走下一步吗？”。本轮据此继续软件开发，将真实琴音／设备矩阵及已知库精度缺口保留为发布前阻塞项。保留原库、原验收标准，没有将合成测试视为实机通过，也没有修补库的检测算法。01 的实机门槛仍未通过，但不再阻塞软件开发；后续票的功能依赖仍按顺序集成。

## 数据保护

- localStorage 保存成功后才更新内存；导入整份校验后一次写入。
- 同记录 ID、同内容去重，不同内容整份拒绝；文件内重复同样处理，内容比较不受 JSON 属性顺序影响。
- 读取损坏存档时保留原始内容，禁止覆盖该数据域，提供原始本地存档导出；不会用空数组的新结果覆盖可救回资料。
- 文件读取串行、提交使用最新资料，离开管理页取消尚未提交的异步读取。
- 尚未保存的本轮在内部页面切换后保留；换目标或再练前要求确认放弃，清理旧记录后可返回重试。

## 已知音频缺口

- 保留 `@kretoffer/guitar-audio-kit@0.0.2`。按目标配置有限检测音域以避免已知宽频段错误峰值；不保证辨别范围外的任意错音或实际来源弦。
- 40 项固定合成诊断仍有 10 项失败；例如 44.1 kHz 的 E6 约偏高 23.33 音分。详见[原始结果](ticket-01-synthetic.json)。
- 430 Hz 基准下，440 Hz 基准的 E2 合成输入可因库误差在 E2/F2 音名边界交替，无法积满稳定窗口；此时保持等待，不放宽稳定门槛强行判断。基准换算另用独立常量验证。
- 手机／桌面真实收音、钢弦／尼龙弦原声吉他、每项 10 次至少 9 次在 1 秒内得到稳定正确结果均未完成。
- 节拍器实际发声的 30／80／240 BPM 各 60 秒累计偏差不超过 100 毫秒，以及真实视听对应尚未测。浏览器状态和 Web Audio 调度配置正确不能替代该报告。
- iPhone、Android、macOS、Windows 当前稳定 Chrome 的完整设备矩阵，触屏及正式视觉人工验收仍待补齐。已直接查看本机初始调音页和和弦页，不能外推为全设备通过。
