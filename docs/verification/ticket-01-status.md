## 具体库能力缺口

发布库版本为 0.0.2，无运行时依赖。已读取发布包源码和类型；PitchDetector 必须在 AudioEngine 初始化完成后创建，因为构造时缓存采样率。未直接使用库的 Tuner：其静音锁定结果与本项目等待规则不符。

合成复现使用发布库实际算法，只在输入边界提供固定波形。完整[40 项结果](ticket-01-synthetic.json)，可运行 `pnpm test:audio` 重现：

- E2 的 60–1500 Hz 宽音域：8 个条件全部失败，44.1 kHz 返回空值，48 kHz 返回 1500 Hz。不能据此提供任意音高识别。
- E2 的 60–110 Hz 窄音域：8 个条件均在本次诊断的 ±20 音分内，最大偏差约 8.61 音分。该诊断门槛**比调音器 ±5 更宽**，不能宣称已经满足调准精度或实机可靠性；当前页面仅用此范围验证 E2 链路。
- E6 在 A4 = 440、44.1 kHz 时返回约 1336.4 Hz，对 1318.5102 Hz 的真实目标约 +23.33 音分；收窄为 1200–1400 Hz 仍未消除误差，超过检测 ±20 门槛。
- 算法整数 lag 没有插值，不能靠扩大参数范围保证高把位精度。应用没有改 FFT、检测算法或人为修正结果。
