日期：2026-10-28。前序 iOS 提交：`605920d`（`feat: add native iOS audio validation app`）。小程序位于 `wechat/`，源教学内容沿用已提交的 Web 版本。

## 当前证据

- `pnpm wechat:data` / `pnpm wechat:check`：14 课、9 练习、12 份曲谱、10 和弦、11 部位与公共数据一致；17 项测试通过。
- 课程检查实际调用全部 14 课的页面逻辑，覆盖逐步推进、自查门槛、完成、重新进入、取消勾选；工具跳转携带一次性意图，返回保留课程位置。
- 曲谱检查覆盖所有 12 份编配的两小节与全曲、弹唱伴奏／旋律区分、筛选空状态、无效链接、分享路径。
- 音频检查覆盖等待恢复时取消、旧拥有者停止、播放位置、分段结束、后台与中断、低版本报错；保留长音、同弦重新起音、休止和范围结尾裁切。节拍检查覆盖 44.1 / 48 kHz、30 / 80 / 240 BPM、2 / 3 / 4 拍、三种细分。
- 存储检查覆盖重新读取、保存失败保留工作、重试、损坏记录不覆盖、重置失败保留原记录。
- 工程页、组件、事件处理器与路径静态检查通过；36 个运行文件，源码体积约 170 KiB，无运行时第三方框架。
- 独立 `wcc` / `wcsc` 检查通过（`miniprogram-compiler@0.2.3` 的旧编译器，仅用于语法检查，未打包进项目）。
- Web 类型检查、lint 和新增小程序源码 lint 通过。共享认琴资料后，Chrome 的「琴身图点选与键盘切换」「TAB／指法图／简谱数字 2」两项定向回归通过。

自动测试中的微信 API 为替身。**尚未用微信开发者工具运行，也未在 iPhone 微信中实际渲染或发声。** 没有二维码、上传或正式发布；不报告视觉通过或真实节拍精度通过。

## 保留的差异

节拍参数修改先停止，不在下一小节自动切换；固定 A4 = 440 Hz，无静音或镜像设置。L1 旧版额外伴奏开关不在首版，专门的 L2 / L3 弹唱编配可练。进度只在当前微信本地保存；不存在账号、云同步或自动演奏评分。音高库的原有误差尚未解决，本版不启用收音。
