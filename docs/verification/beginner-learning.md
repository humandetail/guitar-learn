# 零基础教学验证（2026-10-27）

## 已实现

默认进入学习目录，提供 14 节原创中文入门课，按「认识与准备、识谱与基本功、和弦与伴奏、弹唱与独奏」组织。顺序为完整认琴、持琴与弦品、调音、拍子与音值、识谱、单音、独立爬格子课、短旋律、Em、跟拍、Em/Am 切换、分解伴奏、弹唱、旋律加低音。每节有三个教学步骤及自查。

认琴图可点选 11 个部位，说明位置和用途；三种数字图解区分 TAB 品位、和弦图手指和简谱音级。新增 9 组原创短练习的互动 TAB，可点选位置、逐音查看弦品动作、调速播放合成示范，跟随播放高亮。覆盖空弦、单弦/换弦爬格子、休止、两拍长音、短旋律、分解伴奏、弹唱短句和旋律加低音。TAB 上 1 弦、下 6 弦，不随左手镜像翻转。

学习位置、自查勾选和完成状态使用独立的 `guitar-learn.learning.v1` 存档。完成一课必须成功保存；保存失败保留待保存数据并提供重试，损坏的原存档不被覆盖。可以自由查看或复习各课，刷新可恢复位置。

原六课的 ID、步骤数和自查索引含义保留，新增八课保持未完成状态，不清空旧进度。

课程进入工具时预选 Em/Am 或 60 BPM、4 拍、四分细分，保持手动开始音频。末步的工具入口固定在底部并作为主操作，自查作为次操作。返回课程停止麦克风、节拍器和合成参考音，并回到原步骤。

TAB 播放控件位于谱面上方，普通手机宽度下随滚动停留，当前音自动就近滚入视野；极窄宽度采用普通文档流。示范离开步骤、模块或进入后台时停止，取消等待中的音频解锁后不会迟到播放。麦克风开始时也会停止课程示范。

## 限制

课程完成仅代表用户勾选自查，不是自动验证姿势、手型、节奏或演奏熟练程度。课程提供弹唱与独奏入门练习，不承诺完成后即可演奏任意曲目。示范为合成音，没有真实吉他或人声录音。未新增教学视频、真实人物演示、账号、云同步或任意歌曲导入。学习进度暂不包含在既有练习记录 JSON 备份中。

本次验证使用桌面 Chrome 与移动尺寸模拟，未完成真实吉他、手机麦克风或持琴操作验收。原音频库的已知精度问题继续保留在原验收记录中，本次不宣称已解决。生产构建未作为本次 UI 验证步骤执行。
