# 吉他体验馆验收

2026-11-16 · Web 版

## 浏览器验收

- Chrome 全量 Playwright 回归 127 项通过，其中 12 项是新增的吉他体验馆测试。TypeScript、Lint、生产构建及微信小程序 22 项回归通过。
- 从「学习」进入体验馆，试听、认琴、自由弹、完成三关。浏览器重新打开后可看到通过结果。
- 从「拿稳琴，认清弦与品位」进入空弦和品位试弹。经真琴提示打开其他课程，再返回体验馆，仍能回到原课程步骤。
- 在 320 × 568 的 Chrome 视口模拟触屏跨过琴弦，观察真实 Web Audio 排程。验证六根空弦的频率和跨多个指针事件的起音顺序。另验和弦静音弦、键盘操作、自定义 A4 基准音、左手镜像，以及等待音频解锁时切换模块。
- 在 Chrome 中直接操作 3D 琴面，验证旋转、缩放、点品、拨弦与拖扫。切换 2D 和 3D 后保留品位和关卡位置。模拟 3D 模块加载失败时，2D 仍可按品和拨弦。
- 用 WebKit 的 iPhone 视口检查生产构建。触屏拨弦、变品、课内往返、3D 初始化与切回 2D 后发声通过。3D 旋转的触屏自动化超时，留在真机验收项中。

## Standards

评审确认体验馆沿用项目的标准调弦、基准音和浏览器音频约定。统一了 2D 与 3D 的拖扫判定，按实际起音时间验证跨事件顺序，并用直接点按和拖动补验 3D 琴面。

## Spec

评审后补齐了嵌套打开课程的原位置恢复。第二关在手势跨过至少两根发声弦后计入扫弦，以第一次发声的输入时刻判定早晚。取消旧的音频解锁请求后，新拨弦可以独立重试。

## iPhone Safari 真机待验收

- 实际听辨单弦、扫弦及三种试听，确认首次触屏拖扫和切到后台后的停声行为。
- 验证扫弦区外可正常滚动，确认 3D 旋转、缩放、点品和拨弦在掌上尺寸下容易操作。用左手镜像再试一轮。
- 从体验馆进入调音器或逐弦和弦检测，确认启动麦克风时体验馆停声。

浏览器自动化观察的是用户交互和 Web Audio 排程。真机结果需在实际 iPhone 上记录。
