# Guitar Learn MVP

## 目标
做一个浏览器端的吉他练习工作台，帮助初学者完成“调音 → 跟节拍 → 看和弦 → 检查按弦”的闭环。

## 零基础教学扩展（2026-10-27）
用户确认需要从零开始、一步步学习吉他的引导，目标包含自弹自唱与看谱弹独奏。新增“学习”作为默认入口，与原有四个练习模块并列，以下扩展取代原先“只做四个模块”和“不做 TAB”的限制：

- 14 节固定顺序课程：完整认琴、持琴与弦品、调音、节拍与音值、识谱、单音、独立爬格子课、短旋律、Em 和弦、跟拍、Em/Am 切换、分解伴奏、弹唱与旋律加低音。按四阶段组织，每课由目标、短步骤、图示、实际练习和自查组成；可自由访问或复习，不强制锁课，也不把爬格子速度作为后续学习门槛。
- 认琴图可选择常用部位，说明位置和作用；识谱课区分 TAB、和弦图、简谱与五线谱的用途，重点教授 TAB 弦号、品位、顺序、同时音和时值。
- 内置 9 组原创短练习的互动 TAB，支持逐音查看、40/50/60/80 BPM 合成示范及同步高亮。覆盖空弦、爬格子换弦、休止、长音、短旋律、伴奏与旋律加低音。左手设置不翻转 TAB；离开步骤、模块或进入后台停止播放，麦克风检测与示范互斥。
- 课程可进入对应工具，预选课程和弦或 60 BPM 四拍练习；不自动开启麦克风或播放声音。提供回到原课程步骤的入口。
- 在当前浏览器保存课程位置、自查勾选和完成状态；刷新可继续，保存失败明确提示，损坏资料不静默覆盖。学习进度与原练习记录独立，暂不纳入原记录 JSON 备份。
- 原六课的稳定 ID、三个步骤与自查索引含义保留，扩展后不清空已有学习进度；新增课程作为未完成课程显示。
- 完成状态来自用户自查，不将音高检测当作姿势、手型、节奏或熟练程度的认证。音频正式验收限制继续适用。
- 不新增账号、云同步、AI 教练、视频制作或歌曲版权素材；教学图示随应用提供。

## 入门曲谱扩展（2026-10-27）

用户希望查阅常用曲谱，并指定由项目按零基础选取第一批曲目。学习目录新增「入门曲谱」，先提供《玛丽有只小羊羔》《小星星》《两只老虎》的公共领域旋律、自编入门编配：

- 单音旋律 TAB 与 G/C/D 开放和弦伴奏分开展示。先练旋律，伴奏明确标记新和弦要求，并提供指法图；不将单音版标成完整指弹编曲。
- 支持全曲查阅、每两小节练习、逐音动作提示与调速合成示范。分段保留全曲小节编号；切段、模式、曲目或离开模块停止声音。示范不是演奏评分。
- 列出曲目难点、练习建议、前置课程和来源。保留传统旋律；《两只老虎》统一放大音值便于按整拍慢练，并明确说明版本。
- 不自动标记课程完成，不新增学习存档格式、收藏、账号或曲谱导入；仍保留既有学习进度。

## 分级曲库扩展（2026-10-27）

用户进一步确认需要「从入门一路到完整弹唱、指弹独奏的分级曲库」。这次扩展接续上面的三首入门曲谱：

- 五级学习顺序：L1 单音入门、L2 和弦配唱、L3 完整弹唱、L4 旋律加低音、L5 完整指弹。等级属于项目内的编配难度，不等同于考级或专业演奏认证。
- 首批 4 首旋律、12 份完整教学编配；《欢乐颂》指完整主题，不指整部交响曲。同曲跨级保留旋律，逐步添加伴奏节奏与独立声部。
- 路线与阶段筛选允许自由查阅；两条路线共享单音基础。每份谱包含具体技巧分解、前置课程、慢练方法和自查标准。
- 弹唱包含原创中文练习词、带逐音歌词的旋律跟唱谱和独立伴奏谱；页面标明歌词为本项目创作，不冒充通行译词或原词。
- 指弹版安排实际低音、主旋律与填充音。六线谱及合成示范支持半拍、附点音值、独立延音；同一弦再次拨响或遇到休止时前音结束，选段末尾声音停止。
- 保留旧三首的单音与基础和弦模式、所有课程稳定 ID 及已有学习存档。曲库浏览、筛选和分段不写入课程完成状态。
- 继续使用标准调弦、无变调夹与开放把位；本批终点为完整的初级指弹编配，暂不覆盖高把位、特殊调弦或复杂打板。

## 原有练习模块
1. 调音器：麦克风输入，用户选择目标弦，显示实际音名和相对目标的音分偏差，覆盖全部 6 根标准空弦，重点验证 E2。
2. 节拍器：30–240 BPM，支持每小节 2／3／4 拍、第一拍重音及四分／八分／十六分细分，视觉脉冲 + 可选合成 click 音。
3. 和弦库：内置 C、D、E、G、A、Am、Dm、Em、A7、D7 共 10 个基础开放和弦，每个提供一种固定指法；提供指法图、整和弦及单弦合成参考音。支持自定义和弦新增、编辑、删除及 JSON 导入导出，允许第 1–24 品和横按指法。和弦库与逐弦检测共用同一套指法。
4. 和弦检测：选择一个目标和弦，用户按提示一次弹一根弦，逐根检查音高是否符合目标指法，能区分 Am 和 C 的指法。此处“按对”仅表示音高符合目标，不验证具体手指或手型。

四个模块配套提供本地设置、练习记录列表与详情、记录删除及独立 JSON 备份恢复。移动端优先、桌面兼容；当前稳定版 Chrome 为正式验收浏览器。具体边界见下方已确认条目。

## 明确不做
- 不做用户系统、登录、后端数据库。
- 不做任意歌曲导入、谱站链接解析或自动生成曲谱；只提供上述固定教学练习及精选分级编配的 TAB。
- 不做手型姿态识别、摄像头输入。
- 不做 AI 对话教练、学习路径推荐。
- 原 Web MVP 不做原生手机应用；浏览器端采用移动端优先、桌面兼容。2026-10-28 用户另行授权 iOS App，先做 E2 收音与基础节拍验证版，见 [iOS 范围与安装说明](../ios/README.md)。Web 的完整功能与验收结论不自动迁移到 iOS。

## 技术约束
- React + TypeScript + Vite。
- 音频检测必须在浏览器端完成，使用 @kretoffer/guitar-audio-kit，不自己实现 FFT。
- MVP 阶段不引入后端，自定义和弦、练习记录及设置存 localStorage；预留同步接入点但不实现账号或云同步。
- 基准音 A4 可选 430–450 Hz，步长 1 Hz，默认 440 Hz；各音高功能统一使用该基准和十二平均律，仅支持标准调弦、无变调夹。
- UI 用 shadcn/ui + Tailwind；用户已选定 oil-ui 方向 A“六弦工作台”，以冷灰白、钴蓝和六弦轨道为视觉基线，检测结果同时用文字和图标表达。移动端优先；设计稿与初步视觉规范见 [已选设计方向](design/2026-10-25/oil-ui-a/README.md)，实际字体、尺寸与交互仍需实现时验证。

## 验收标准
- 调音器能在浏览器中识别全部 6 根标准空弦的 E2、A2、D3、G3、B3、E4，并显示相对目标音的音分偏差；音高略高或略低时偏差方向正确，E2 为重点测试项。
- 节拍器在前台以 30、80、240 BPM 连续运行 60 秒，并覆盖十六分细分，累计节拍时间偏差不超过 100 毫秒；声音不得漏拍或突然连发，视觉脉冲与声音保持对应。
- 和弦库能展示 10 个内置开放和弦及自定义和弦的指法图，支持整和弦及单弦参考音；手指编号可关闭，指法图可切换左手镜像。
- 自定义和弦的新增、编辑、删除、JSON 导入导出按 Q7–Q10、Q13、Q43–Q44、Q52、Q56–Q57 验证；练习记录的查看、备份恢复、去重及删除按 Q14–Q17、Q26、Q53–Q55 验证。
- 和弦检测通过用户按提示逐弦弹奏，对目标指法逐弦给出“音高符合目标／音高不符”的判断，至少能区分 Am 和 C；匹配八度且偏差在 ±20 音分内（含边界）视为符合，不弹弦跳过。不要求一次扫弦后同时判断所有弦，也不验证实际发声弦位、品位、手型或消音。
- 音频响应与稳定识别按 Q51、Q66–Q67 验证；手机内置麦克风及桌面麦克风均纳入范围。音频异常、后台中断及声音恢复按 Q30、Q38–Q40、Q47–Q48 验证。

## 已确认的边界
- Q1：和弦检测采用逐弦弹奏、逐根检查音高的方式；不验证具体手指或手型，不要求整把扫弦识别。
- Q2：MVP 仅支持标准调弦（第 6→1 弦为 E2、A2、D3、G3、B3、E4），且不使用变调夹。
- Q3：内置和弦为 C、D、E、G、A、Am、Dm、Em、A7、D7；每个提供一种固定指法，和弦库与逐弦检测共用。
- Q4：MVP 提供用户新增、编辑和导入和弦的入口。
- Q5：自定义和弦与内置和弦均支持指法图展示、参考音播放和作为逐弦检测目标；仍限标准调弦、无变调夹。
- Q6：自定义和弦允许横按及高把位指法；每根弦可设置“不弹”、空弦或第 1–24 品。检测仍仅检查目标音高，不验证横按动作或具体手指。
- Q7：内置的 10 个和弦不可直接修改；用户可复制为自定义和弦后编辑。自定义和弦可直接修改。
- Q8：和弦导入仅支持本应用定义的 JSON 文件，可包含多个和弦；每个包含名称及第 6→1 弦的“不弹／空弦／品位”数据。不支持图片识别、谱站链接或其他软件格式。
- Q9：新增、编辑或导入时遇到同名和弦，保留已有资料，为新名称自动添加后缀以区分，不覆盖已有资料；导入项例如“C（导入）”“C（导入 2）”。
- Q10：导入前校验整份文件，任何条目无效则整份拒绝，并指出具体条目和原因。每个和弦须名称非空、恰好包含 6 根弦、各弦值符合 Q6 的范围，且至少一根弦可弹奏。
- Q11：MVP 的练习记录和自定义和弦仅保存在当前浏览器的 localStorage；接受换设备、换浏览器或清除网站数据后无法自动恢复，并在界面明确提示。预留未来账号或云同步的接入点，MVP 不实现账号或云同步；具体范围见 Q12。
- Q12：同步接入点的范围为：自定义和弦及练习记录具有稳定 ID，集中管理本地读写，并预留同步状态和删除标记的扩展位置。MVP 不实现登录、云端请求、自动同步或冲突合并。
- Q13：提供一键导出全部自定义和弦的 JSON 文件，沿用 Q8 的导入格式，可通过现有导入入口重新导入，用于备份、分享或手动迁移。
- Q14：每完成一轮逐弦和弦检测，保存一条练习记录，包含练习时间、目标和弦及当时的指法、各弦检测结果。调音器和节拍器不产生练习记录，不保存麦克风录音；旧记录保留练习当时的指法，不随自定义和弦后续编辑而改变。
- Q15：MVP 增加练习记录的文件导出与恢复功能，具体规则见 Q16、Q17。
- Q16：恢复练习记录时与当前记录合并，按稳定 ID 去重并保留当前已有记录；重复导入同一份备份不增加重复记录。同一 ID 内容不同时，整份拒绝并提示冲突，不静默覆盖。
- Q17：练习记录使用独立的 JSON 备份文件，一键导出全部记录，包含格式版本、记录 ID、练习时间、目标和弦及当时的指法、各弦结果。恢复前整份校验，无效则整份拒绝；恢复记录不自动向和弦库新增和弦。
- Q18：目标指法标记为“不弹”的弦跳过检测，显示“不弹／未检测”，不计为“按对”。一轮练习仅检查应发声的弦，不验证消音效果。
- Q19：未收到可可靠识别的清晰、稳定单音时，显示“等待弹奏／请单独重弹”，不判为“未按对”，不自动进入下一根弦。仅在识别到有效单音后判断音高是否符合目标。
- Q20：某弦获得有效检测结果后，无论对错都保留在当前弦，由用户点击“下一弦”推进；用户可留在当前弦重测，以最近一次有效结果为准。完成后展示整轮结果。
- Q21：按第 6→1 弦顺序检查，跳过“不弹”的弦。所有应发声弦均有有效结果后，用户点击“完成”才保存一条记录，有错音也算完成。中途退出或切换目标和弦则放弃本轮，不保存部分记录。
- Q22：“按对”须匹配目标八度，且相对目标音高的偏差在 ±20 音分内（含边界）；超出范围或八度不匹配判为“未按对”。MVP 不提供容差设置，后续通过实际试弹评估是否调整。
- Q23：调音器由用户先选择第 6→1 弦中的目标弦，默认第 6 弦 E2；显示目标音、实际识别音及相对目标的音分偏差。
- Q24：允许用户选择基准音，默认 A4 = 440 Hz；可选范围与步长见 Q25，跨模块应用规则见 Q26。
- Q25：基准音 A4 可选 430–450 Hz，步长 1 Hz，默认 440 Hz，并提供“一键恢复 440 Hz”。
- Q26：所选基准统一作用于调音器、和弦参考音和逐弦检测，使用十二平均律计算音高；练习记录及其备份保留当轮使用的基准，旧结果不随后续设置变化而改变。
- Q27：一轮逐弦检测进行中锁定基准音设置；本轮完成或退出后才能修改，避免同一轮各弦按不同基准判定。
- Q28：调音器须对全部 6 根标准空弦通过验收，识别 E2、A2、D3、G3、B3、E4；音高略高或略低时显示正确的偏差方向，E2 为重点测试项。
- Q29：调音器在相对目标音偏差 ±5 音分内（含边界）显示“已调准”；超出时，低于目标提示“调高”，高于目标提示“调低”，始终保留音分数值。和弦检测容差仍为 Q22 的 ±20 音分。
- Q30：麦克风检测期间暂停应用自身的节拍器 click 和和弦参考音播放，视觉节拍可继续运行。
- Q31：节拍器 BPM 范围为 30–240，默认 80，步长 1；提供数值输入和加减按钮，超出范围时提示有效范围。
- Q32：节拍器 click 使用浏览器实时合成的短音，不依赖音频文件。
- Q33：节拍器支持每小节第一拍重音；每小节可选 2、3、4 拍，默认 4 拍。第一拍使用不同音高的 click，并在视觉上突出。
- Q34：提供四分、八分、十六分三档细分，每拍分别播放 1、2、4 次 click；BPM 仍表示每分钟的拍数，小节重音保留在第一拍。
- Q35：视觉脉冲跟随每次细分 click，区分主拍、细分和小节第一拍，并显示当前拍号位置；关闭声音后保持相同的视觉节奏。
- Q36：节拍器运行中修改 BPM、每小节拍数和细分档位，统一在下一小节第一拍生效，界面提示“下一小节应用”；停止状态下修改立即生效。
- Q37：首次使用时节拍器声音开关默认开启；打开页面不自动运行，用户点击“开始”后才播放 click，可随时关闭声音并仅保留视觉节奏。
- Q38：页面切到后台时暂停节拍器；返回页面后由用户手动继续，从小节第一拍重新开始，不补播暂停期间的节拍。MVP 不承诺后台持续运行。
- Q39：调音器与逐弦检测互斥使用麦克风，启用其中一个时停止另一个；从未完成的逐弦检测切换至调音器时，放弃本轮并提示本轮不会保存。
- Q40：麦克风检测结束后，节拍器 click 不自动恢复，提供“恢复节拍器声音”按钮；和弦参考音需用户重新点击播放。
- Q41：和弦参考音提供“播放和弦”和单弦播放；整和弦从第 6→1 弦快速依次发声以模拟一次扫弦，跳过“不弹”的弦；点击指法图中的某根弦只播放该弦目标音。
- Q42：和弦参考音采用一种合成拨弦音色，界面标明“合成参考音”；验收要求音高准确、声音清晰，不要求逼真还原真实吉他音色。
- Q43：指法图支持手指编号（1 食指、2 中指、3 无名指、4 小指），在设置中允许关闭显示。内置和弦提供编号，自定义和弦可选填，未填写时只显示按弦位置；编号用于教学提示，不参与音高检测判定。
- Q44：自定义和弦支持选填横按品位、起止弦和手指编号，指法图以横条显示；导入、导出保留这些资料，逐弦检测仍只依据各弦目标音高。
- Q45：指法图提供左手持琴的镜像显示设置，默认右手持琴；镜像后保留弦号标注，和弦资料、音高及检测顺序仍按第 6→1 弦定义。
- Q46：用户设置保存在当前浏览器并在下次打开时恢复，包含基准音、左右手方向、手指编号显示，以及节拍器 BPM、每小节拍数、细分和声音开关。首次使用默认显示手指编号；恢复设置不自动启动音频功能。
- Q47：麦克风授权被拒绝、不可用或中途断开时，显示原因和重试入口，停止调音器或逐弦检测并释放麦克风；未完成的检测按中断规则放弃。和弦库、参考音及节拍器仍可使用，声音按 Q40 手动恢复。
- Q48：页面切到后台时停止麦克风检测并释放麦克风；未完成的逐弦检测按中断规则放弃，返回后提示“本轮未保存”，由用户重新启动。调音器也需手动重新启动。

- Q50（已由 Q62 扩充）：音频检测以安静室内、钢弦或尼龙弦原声吉他经手机内置麦克风或电脑内置／外接麦克风逐弦收音为验收场景；电吉他直连声卡、失真效果器及嘈杂环境暂不纳入保证范围。
- Q51：清晰单弦弹奏后，以 1 秒内显示稳定结果为调音器和逐弦检测的响应目标，忽略拨弦瞬间的短暂波动；无法在 1 秒内可靠识别时继续提示等待或重弹，不强行判对错。
- Q52：提供自定义和弦删除功能，删除前确认；删除不影响关联练习记录，旧记录保留当时的名称、指法和基准。内置和弦不可删除。
- Q53：练习记录按时间倒序显示列表，列出时间、和弦名称及正确弦数；单次详情显示当时的指法、基准音和逐弦结果。MVP 不做趋势图、排行榜或练习评分。
- Q54：练习记录支持“删除单条”和“清空全部”，操作前确认；清空仅影响练习记录，自定义和弦及设置保留。MVP 不提供回收站或撤销，已导出的备份仍可重新导入。
- Q55：练习记录不设自动过期，不自动删除旧记录，由用户自行清理。本地空间不足时明确提示“保存失败”，保留本次结果供查看，并提供导出或清理入口，不显示保存成功。
- Q56：新增、编辑或导入和弦保存失败时，保留原有资料和未保存内容，不留下部分导入结果；明确提示未保存，提供重试或导出待保存内容的入口。
- Q57：手指编号或横按资料与各弦品位明显冲突时，禁止保存或导入，并指出具体位置。手指编号可不填；填写后校验数据一致性，不评估指法的人体工学或初学者适用性。
- Q58：允许使用 @kretoffer/guitar-audio-kit 的底层音高检测接口并配置检测音域；频率检测交给库，应用负责基准音、品位、目标频率及音分换算和判定规则，不自行实现 FFT。实际麦克风精度及 1 秒响应目标须实测验证。
- Q59：当前目标弦由练习步骤指定，系统仅核对收到的音高，不承诺识别声音实际来自哪根弦、哪个品位或何种手型。界面采用“音高符合目标／音高不符”，同音高来自其他弦时不承诺辨别。
