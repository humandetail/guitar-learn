## 发现与处理

| 发现 | 修正与复核 |
| --- | --- |
| Am 图第4弦与第3弦的手指2、3互换，第二品圆点高度不齐 | 已校正为第4弦第二品指2、第3弦第二品指3；圆点同排。指法为x02210，与编辑表一致 |
| F3 +100音分落在±50刻度内部 | 异常示例改为±100刻度，+100指针在最右端；目标仍为E3，状态为音高不符 |
| 80BPM滑块位置不符合30–240的线性比例 | 已向左修正；静态生图的位置仍为近似，不能据图声称达到精确23.8%。实施时必须按(80−30)/(240−30)=23.81%计算，不照抄图中像素 |
| 设置页边框、卡片与小字竞争 | 取消手指编号、持琴方向及记录入口的重复外框，保留必要分组；缩短手指说明 |
| 五个基准音快捷档无法在静态图明确表达1Hz调节 | 改为加减数值控件，明示430–450Hz、步长1Hz；评审已说明原有披露箭头可能通往完整选择器，此项是澄清而非已证实的流程阻断 |
| 检测顶部步骤与六条轨道重复 | 等待与错音两屏移除重复步骤栏；保留当前目标与六弦轨道 |
| 六弦长线与当前读数争注意力 | 降低待测轨道颜色，汇总状态不再挤入窄列；保留六弦结构作为所选方向的识别点。核心稿轨道高度仍偏大，后续可继续压缩 |

## 保留
