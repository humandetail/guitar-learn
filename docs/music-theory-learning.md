# 乐理学习设计讨论

状态：已根据用户调用 to-spec 汇总并发布为[功能规格](../.scratch/music-theory-learning/spec.md)，标记 ready-for-agent；现已实现 Web 与微信三阶段软件功能，验收结果见[交付记录](verification/music-theory.md)。

## 已确认

- 近期先帮助初学者看懂正在弹奏的内容，再逐步培养迁移到新歌曲的能力，最终覆盖移调与编配。
- 乐理知识随弹奏课穿插，并提供集中复习入口。
- 每个知识点配小任务和答案解释，允许跳过与重试；实际弹奏部分由用户自查。
- 乐理不作为弹奏课的解锁条件，单独记录学习状态；答错时提供解释与复习入口。
- 全部纳入并分阶段交付：音名与指板、节奏与时值、音级与调、和弦基础，以及五线谱系统教学、复杂和声、移调与编配。
- 首次交付覆盖 Web 与微信小程序；iOS 在迁入完整课程时接入。

## 分阶段交付

| 阶段 | 内容 | 学习成果 |
| --- | --- | --- |
| 一：看懂正在弹什么 | 音名、指板、时值、音级、C 大调、基础音程、大小三和弦 | 能解释简单旋律与和弦 |
| 二：读谱与迁移 | 五线谱基础到常用读谱、其他常用调、调号、移调、顺阶和弦与常见进行 | 能把熟悉的知识用到新歌曲 |
| 三：理解与编配 | 七和弦、和弦功能、转位、属和弦扩展、借用和弦，以及旋律配和弦与伴奏编配 | 能为简单旋律制作并解释自己的伴奏 |

第三阶段用具体歌曲案例限定复杂和声的深度，后续再扩展。

## 任务与学习状态

- 小任务包含选择／判断、点选指板或谱面、听示范后辨认三类。
- 首版听辨采用选项作答，拿琴操作附自查提示。
- 区分“已阅读”和“练习通过”：跳过题目只记录已阅读，全部小任务答对后记录练习通过，重试不限次数。
- 拿琴操作的自查单独标明，不作为系统已验证的演奏能力。

## 验收依据

以下标准由已确认选择推导，用于后续实现核对，不扩大课程范围：

- 每阶段内容与其学习成果对应，首阶段至少有贯穿音名、指板、节奏、音级和基础和弦的学习路径。
- 弹奏课可进入相关乐理内容，集中复习入口可找到对应知识点。
- 小任务提供答案解释，可跳过、重试；跳过或答错不会阻断弹奏课。
- 已阅读、练习通过与演奏自查分别表达，不能将看完内容或自查等同于系统验证演奏达标。
- Web 与微信小程序覆盖相同的阶段内容和学习状态含义；iOS 随完整课程迁入。
